Keyboard Movement

Keyboard control is useful for quick, small adjustments. Each key press sends one relative movement to every connected device.

Key Mapping

  • Q / W: move along −X / +X.
  • A / S: move along −Y / +Y.
  • Z / X: move along −Z / +Z.

The value beside each pair sets the distance for one key press. The speed setting is shared by all three axes.

Turning It On

Connect at least one device, then set Keyboard control to Enabled. It switches off automatically when the last device disconnects.

Press the keys without Ctrl, Alt, Shift or Command. Holding a key down will not keep sending movements.
