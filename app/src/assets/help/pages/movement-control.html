Movement Control

Use this panel to home the connected devices, set their origin, or send a movement.

Homing

Home tells every connected device to move all axes to their hardware home position using G28.

This can start motion immediately. Make sure the path is clear, the limit switches are working, and every connected device can be homed safely. The exact sequence depends on the controller firmware.

Setting the Origin

Set Current Position as Origin marks the current X, Y and Z position as zero using G92 X0 Y0 Z0. It changes the coordinates but does not move the device.

Absolute movements will use this new origin. Homing is different: it finds a hardware reference, while setting the origin creates a coordinate reference wherever the device is now.

Movement Type

  • Relative: move by the entered distance from the current position.
  • Absolute: move to the entered coordinates relative to the current origin.

Coordinates and Speed

Enter X, Y and Z in millimetres and the speed in millimetres per second. Click Send Movement to send the same G1 movement to every connected device.

Before sending it, double-check the movement type, origin, coordinates and available travel.
