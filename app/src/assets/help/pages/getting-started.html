Getting Started

Launch the Application

On Linux or macOS, open a terminal in the project folder and run the launcher for your system:

  • Linux: ./Linux_Position_Controller.sh
  • macOS: ./Mac_Position_Controller.command

On Windows, double-click Windows_Position_Controller.bat.

The first run may take a little longer because the launcher downloads Python and the required packages. You only need an internet connection for this initial setup and future updates.

What You Can Do

Position Controller can work with a positioning system that accepts G-code over a serial connection. Connect the controller to your computer, select its serial port and baud rate, then start serial communication.

Once connected, you can home the system, set its current position as the origin, and send relative or absolute movements. You can also use the keyboard controls or send a custom G-code command when needed.
