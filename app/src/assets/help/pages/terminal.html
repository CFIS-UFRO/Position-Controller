Terminal

Use the terminal to follow application activity, including connection changes, warnings, errors, messages sent to devices, and device replies.

Each line shows the time, log level, and message.

Log Levels

  • INFO: normal application, connection, or serial communication activity.
  • WARNING: something unexpected happened, but the application can continue.
  • ERROR: an operation failed.
  • CRITICAL: a serious application error occurred.

Serial Messages

Serial communication appears as an INFO entry with additional labels:

  • [TX] [device] message: a message sent to the named device.
  • [RX] [device] message: a message received from the named device.

TX and RX lines use distinct green colors so they are easy to identify.

The terminal keeps the latest 500 lines, so older entries disappear as new ones arrive.
