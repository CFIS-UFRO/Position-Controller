Terminal

Use the terminal to see what the application sent, what the devices replied, and any connection errors.

Each line shows the time, event type, device and message.

What the Labels Mean

  • INFO: general application or connection information.
  • TX: a message sent to a device.
  • RX: a message received from a device.
  • ERROR: something went wrong while communicating with a device.

The terminal keeps the latest 500 lines, so older entries disappear as new ones arrive.
